# Changelog

## 1.0.0

- Weapon light brightness, glow, opacity, size and particle count controls.
- Independent general-setting influence for attack launch, projectile flight and impact.
- Magic shield light brightness, glow, opacity, ovality and color controls.
- One whole-number hue slider for shield color.
- Whole-number settings and immediate updates through F1 Configuration Manager.
- Original visuals restored when the mod or its effect controls are disabled.

## 0.1.1

- Magic shield light, glow, opacity, ovality and hue settings.

## 0.1.0

- One whole-number hue slider for magic shield color.

## 0.0.6

- Stage influence defaults: Attack launch 100%, Flight 0%, Impact 100%.

## 0.0.5

- One magic shield ovality setting with the previous oval appearance by default.
- One shield color field.
- General weapon defaults: light 0%, glow 50%, opacity 25%, size and particle count 100%.

## 0.0.4

- Separate general-setting influence for attack launch, flight and impact, ranging from original visuals to configured effects.
- Original launch and flight appearance with general settings applied to impact by default.

## 0.0.3

- Integer percentages, RGB channels.

## 0.0.2

- Magic shield light, glow, opacity, color with original dimensions.

## 0.0.1

- Universal weapon light, glow, opacity, visual size and particle count settings.
- Additional launch, flight and impact coefficients.
- Separate magic shield light, glow, opacity, color.
- F1 Configuration Manager settings with updates to active effects.
- Original visual values restored when controls are disabled.
